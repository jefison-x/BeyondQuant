# ADR-0069：退役 DSH 0.1.1rc1 日常维护

- Status: Accepted
- Date: 2026-09-10
- Scope: 旧版日常构建、CI、依赖扫描与兼容入口退役；当前 MCP Hono 更新。
- Acceptance: 维护者明确表示“我们没有必要兼容旧版本”，并对“保留历史镜像、备份和验收记录；退役日常构建、CI 和 Dependabot；关闭 #270/#271；处理 #269”回复“好的就这样处理。”
- Supersedes: ADR-0058/0061 中持续为 0.1.1rc1 构建、测试及生成新 Post-U8 认证的要求；历史证据完整性要求不变。

日常构建及运行入口仅支持官方 DSH 0.1.2rc1。当前源码不能创建新的 0.1.1rc1
构建认证，普通配置选择旧版必须失败。旧 npm 清单转为非安装清单的只读档案，
仅供历史来源、许可及冻结注册表验证，不再进入 npm 安装或 Dependabot 更新。
日常 CI 改为当前 bundled runtime 的完整组件及真实进程、预算、生命周期验证。
不将停止旧版测试包装成新版本测试通过，不降低 Product/MCP/领域回归范围。

历史 release、旧 manifest、镜像、备份及验收报告保持不变；旧版应急恢复只能由
另行授权的 operator 使用精确历史制品及对应 runbook，不允许用当前源码重建旧镜像。
历史事件读取、来源识别与已保存业务证据不因运行时退役而丢失。

MCP Hono 由 4.13.2 更新至 4.13.7，核查官方制品与许可，使用新独立构建身份和
完整 CI 交付。#270/#271 因旧版退役关闭，#269 在替代维护 PR 合并后关闭。
本任务允许上述维护 PR 及 CI-green 门禁合并、具名 PR 关闭，不修改 GitHub 检查规则。
不含生产部署、数据删除、历史研究续跑或正式 release/tag；Product Phase 97 不变。

## Accepted amendment — 2026-09-10：清理退役残留

维护者对残留审计明确要求“好的，清理残留”。移除旧 SDK 兼容实现及其专属测试，
保留并迁移仍适用于 0.1.2 的规范化、生命周期与进程清理覆盖。旧 Dockerfile 转为非构建档案，
旧版配置生成和双版本部署/演练入口停止接受新操作。历史清单、来源及许可证据保持可核验。
当前生产运行时镜像不复制测试代码；CI 在同一精确运行镜像上只读挂载测试执行，不降低实际进程验证。
