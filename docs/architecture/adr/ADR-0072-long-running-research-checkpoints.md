# ADR-0072：长研究进度检查与显式期限

- Status: Accepted
- Date: 2026-09-12
- Acceptance: 维护者明确授权“取消根回合15分钟、子 Agent 10分钟默认硬终止；每15分钟检查进度；新后台回合期限随许可有效期，最长24小时；旧许可、预算和取消控制保留”。
- Scope: 本次长研究运行策略维护，Product Phase 97 不变。
- Supersedes: ADR-0062 §2 根900秒/child600秒默认硬上限、§4及ADR-0065每回合900秒默认/最大期限。

正常有可验证运行活动的根回合和子 Agent 不因固定15/10分钟失败。根回合默认每900秒检查，
检查复用既有watchdog和公开waiting投影，不增加模型请求、不续租、不声称业务产生新成果。
运行时间总上限默认0（关闭）；显式非零operator上限仍执行，readiness暴露真实设置。
单次请求超时、无活动租约、F7纠错阻断、取消和后台token准入继续生效。

新后台许可的回合期限缺省随已确认许可有效期（最多24小时），允许明确指定更短期限。
实际预留截止为回合截止与许可到期较早者；旧许可/预留不延长，原请求幂等重放不改期限或额度。
原8回合/token累计预算、撤销/禁用及保守结算边界不变，不追溯授予历史研究许可。
页面显示新规则及当前许可的实际期限，不能把旧900秒许可宣传成已延长。

研究状态/制品独立持久化；等待审批或异步领域作业复用既有通知/续接设施，不新建harness或空轮询。
期限/预算终止保留原回执和恢复上下文；业务任务不伪记完成，恢复仍需有效许可。
持续运行活动不等于业务进展；此修订不扩大F7工具范围，不新增普通前台累计token硬预算。

验证长于旧上限的根/child、检查不续租、无活动/显式短期限、预算/取消、
旧许可重放/重启/迟到结算，以及经Gateway/Product API的真实页面期限显示。
本次授权为开发及隔离验证；不推送/合并/部署，不修改生产环境或续跑历史研究。
