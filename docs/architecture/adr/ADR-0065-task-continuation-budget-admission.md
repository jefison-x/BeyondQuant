# ADR-0065：任务后台续接的累计预算准入

- Status: Proposed
- Date: 2026-09-08
- Scope: 补齐 ADR-0062 §4 中尚未实现、不能以回合数量替代的累计 token/费用预算。
- Acceptance: 未接受；本文件只允许记录问题、设计和隔离资格验证，不允许启用后台模型执行。

## 证据及原假设修正

ADR-0062 要求后台续接保留既有 token/cost 预算，但当前 BYQ Runtime 只实施时间看门狗，
未向官方 DeepSeekHarnessConfig 设置 max_tokens，也没有已验证的任务累计 token/费用准入账本。
Product patch 中 8192 和 4096 分别为压缩/搜索局部限制，不是研究任务总额度。

已锁定官方 SDK/runtime 0.1.2rc1 的无网络容器内验证：配置 max_tokens=8，同一个 SDK
回合仍发出两次 max_tokens=8 的本地合成请求，最终 completed。合成响应每次报告8个输出token；
这些是脚本夹具而非真实模型用量。该证据证明此参数不是整个多步骤回合的累计预算，
不证明官方所有潜在插件或接口都缺少预算能力。尚无合格证据可声称子 Agent、搜索、压缩及
失败重试的费用都受一个任务总限额约束。测试未调用外部 Provider 或任何业务工具。

## 建议决策（待接受）

1. 保留 ADR-0062 的强限制，不降级为“8回合即可保证费用”或仅事后提示。24小时、最多8个
   后台回合、每回合900秒及累计预算均为独立门禁，以先耗尽者为准。
2. 新增 BYQ-owned 任务预算合同和准入账本，绑定现有任务、用户/工作区、会话、许可版本及
   已确认制品；后台执行前持久预留额度，重启不清零，重复通知不重复预留/执行。
   用户必须明确确认额度，不推定默认金额，不追溯给历史任务授权。开发测试付费授权不是
   Product 用户的后台费用许可。
3. 优先资格验证官方 DSH 公开、受支持的预算或模型调用前拦截接口；DSH 保持通用编排所有者，
   BYQ 只提供已获授权的有限额度。必须覆盖根模型、子 Agent、搜索、压缩、Provider 重试和
   并发请求，不能仅覆盖公开回答或工具数量。暂未证明存在这样的合格接口。
4. 任何额度返还必须有精确的可验证结算证据；提交/用量未知时保留预留，不自动补充。
   使用金额限额时，需固定币种、模型/Provider 和可验证保守价格上界；缺失、过期或无法覆盖
   全部调用时禁止后台启动，不将估算宣传为硬上限。单次响应 max_tokens 仅作额外限制。
5. 取消、撤销、身份禁用、许可到期和额度耗尽阻止新的准入；须定义并发准入/撤销的事务顺序，
   区分已准入回合与尚未准入意图，并通过真实进程与丢回执测试证明，不声称跨服务瞬时原子性。
6. 此决定不授权 fork/升级 DSH、注入未公开 hook、在线安装扩展、建立 Provider 代理、
   第二通用 harness 或让 DSH 访问业务数据库。若公开接口无法实现硬限制，维持后台执行关闭，
   报告具体阻碍并另行决策，不能擅自采用上述替代路线。

## 验收及非目标

先用隔离脚本 Provider 证明超额前拒绝、子调用覆盖、预算跨重启、并发预留、重复事件、
取消/撤销竞争、迟到及未知结算。付费 API 仅用于获授权的关键资格点，不调用生产身份、
真实对话或历史研究。用户可查看剩余额度及明确阻塞原因；正常领域审批仍逐动作执行。
本 ADR 不授权生产部署、历史任务续跑或数据扩容。其他不依赖该预算门禁的整改仍可继续。
