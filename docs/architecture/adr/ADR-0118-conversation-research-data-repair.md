# ADR-0118: 会话内有界研究补数

- Status: Accepted
- Accepted: 2026-11-24，维护者明确回复“接受 ADR-0118，继续改造”
- Date: 2026-11-24
- Scope: 普通登录用户的当前个人会话与既有 A 股研究数据准备能力。

## 背景

2026 年 11 月 24 日的生产研究中，11 月 18 日行情同步已因供应商不可用耗尽重试。当日交易日历尚未落库，现有定时任务在 18:30 才刷新截至当天的日历。研究会话只能提示普通用户将适用的补数范围交给管理员。

## 决策

1. 在现有 Data Worker 中独立刷新当天缺失的上交所交易日历。继续使用启用开关、已配置供应商与现有校验。日历就绪不代表收盘行情可用。收盘同步的配置、日期检查与权限不变。
2. 登录用户在自己拥有的活动个人会话里可以申请补齐研究所需的已支持数据。对明确研究请求中发现的缺项，产品可按本规则自动提交准备。后台核验会话归属、精确保留范围、数据种类和幂等性。每次至多 20 只股票、180 个自然日，并且最多触及 5 个需整日补数的交易日。分页查询或重试不能突破该上限。每个个人工作区同时最多一个活跃的用户自助准备请求。
3. 数据中心复用标准数据范围与已有准备任务，全局共享的行情按规范要求去重，产品回执按会话和工作区鉴权。新请求先重新检查现有数据，复用已有任务和已有验证结果。已达失败终态后，可基于原回执和精确范围进行有冷却的有限重试；每个共享的标准补数范围至多自助重试一次，距失败终态至少 5 分钟。同一个整日同步任务也只能被自助重新排队一次。保留原失败证据，沿用供应商调用退避和单任务重试限制。后台核验就绪后，原会话可读取状态并用真实补齐数据继续研究。
4. 浏览器经 Product API 提交，Agent 经 BYQ MCP 申请。Backend 决定准入，Data Worker 是唯一执行者。普通用户新增的是有界研究准备能力。凭据管理、全量同步、调度设置、非本会话数据及其他管理操作仍受现有权限约束。
5. 数据中心区分不支持的数据品类、已支持但尚未发布、准备中、已核验就绪和供应商执行失败。尚未接入的数据品类才提示建设需求。范围超限或供应商失败走对应状态和管理员处置，无需为同一品类重复登记需求。

## 验收

- 盘前获取当天日历，保持行情任务不入队。已存在有效日历时复用，供应商失败按现有退避。
- 普通用户在原会话对 11 月 18 日类型的缺口可发起准备。重复及并发触发合并，跨会话访问无泄露，管理员配置接口继续拒绝普通用户。
- 结果只有通过实际覆盖复查才标为就绪，已支持但失败及未接入美股结构化行情显示不同状态。
