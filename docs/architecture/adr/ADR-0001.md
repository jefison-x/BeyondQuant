# ADR-0001：采用 DeepSeek Harness 作为 BeyondQuant Agent Harness

## 背景

BeyondQuant 需要通用 Agent runtime，同时必须保留自身的量化 domain invariant、
Product Contract、安全边界和研究方法。历史仓库包含过去的 Agent runtime 架构，
但其实现历史不是新项目的权威依据。

## 决策

BeyondQuant 采用 DeepSeek Harness 作为通用 Agent Harness，同时将全部量化 domain
invariant 保留在 BYQ 内。

DSH 负责 session、context、compaction、skill、preset、subagent、generic workflow、
tool registration、MCP client behavior 和 generic guard 等通用 Agent 基础设施。BYQ
负责量化领域能力，并通过 BeyondQuant MCP 暴露这些能力。

BYQ 不 fork DSH。DSH 版本必须准确固定，通过 compatibility boundary 集成，并由
contract test 和 upgrade test 保护。

## 后果

- BYQ 可以使用持续维护的通用 Agent 基础，而不创建第二套 Harness。
- 量化语义继续由 BYQ 持有、测试和审计。
- Agent-to-Domain 调用具有稳定的 BeyondQuant MCP 边界。
- DSH upgrade 在用于 production 前必须通过 compatibility 和 Contract 验证。
- Product Plane 与 Engineering Plane 的 privilege 继续独立治理。
- 历史实现可以作为参考材料，但必须依据新架构评估，不能整体复制。
