# ADR-0001: Adopt DeepSeek Harness as BeyondQuant Agent Harness

## Context

BeyondQuant needs a general-purpose agent runtime while preserving its own quantitative domain invariants, product contracts, security boundaries, and research methodology. Historical repositories contain prior agent-runtime architectures, but their implementation history is not the authority for this new project.

## Decision

BeyondQuant adopts DeepSeek Harness as its general-purpose agent harness while retaining all quantitative domain invariants inside BYQ.

DSH owns generic agent infrastructure such as sessions, context, compaction, skills, presets, subagents, generic workflows, tool registration, MCP client behavior, and generic guards. BYQ owns quantitative domain capabilities and exposes them through BeyondQuant MCP.

BYQ will not fork DSH. The DSH version will be pinned exactly, integrated through a compatibility boundary, and protected by contract tests and upgrade tests.

## Consequences

- BYQ can use a maintained general-purpose agent foundation without creating a second harness.
- Quantitative semantics remain owned, tested, and audited by BYQ.
- Agent-to-domain calls have a stable BeyondQuant MCP boundary.
- DSH upgrades require compatibility and contract validation before production use.
- Product and Engineering Plane privileges remain independently governed.
- Historical implementations may provide source material, but they must be evaluated against the new architecture rather than copied wholesale.
