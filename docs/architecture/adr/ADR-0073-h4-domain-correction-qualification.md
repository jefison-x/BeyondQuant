# ADR-0073：H4 领域工具纠错的逐项资格扩展

- Status: Accepted
- Date: 2026-09-13
- Related: ADR-0066、ADR-0067、RESEARCH_HANDOFF_PLAN H4
- Acceptance: 2026-09-13 维护者在本任务中明确回复“接受方案”，接受此前提交的 ADR-0073 草案及其逐项资格门槛。

## 问题

ADR-0066 规定先资格验证、后接入，并要求其他工具逐项独立审计；首批具名范围是策略校验与 ML 策略创建。
H4 要补完整接口清单。自动审批认为将策略版本创建加入调用凭证动作集合仍需显式 ADR 范围，
拒绝了尚未执行的清单修改和回环官方进程测试。本决策明确后续扩展门槛，避免把已有三工具的通过推广成全部通过。

## 决定

1. 在当前 H4 维护范围内，允许对现有 BeyondQuant MCP 领域写工具逐项开展隔离资格验证。
   每项须有独立证据记录及具名动作；首个候选是已存在的 `byq_strategy_version_create`。
   这不是允许任意新工具自动加入：仅涉及当前工具清单已有动作，不扩大角色工具权限或业务权限。
2. 可复用 ADR-0066 接缝的动作必须具备：可信根回合和原 AgentRun、已经存在的原研究任务、
   原请求身份及完整有界输入摘要。缺少任一条件，不得用最新 active run、生成任务或模型自报身份补齐；
   无法适用现有合同的动作必须保留未完成，另行提交设计。
3. 资格阶段允许在隔离工作树修改该动作的候选私有合同和测试，运行锁定的官方 DSH 进程。
   模型、MCP 和外部 Provider 端点限本地合成测试服务；禁止读取真实模型密钥、付费请求、生产领域写入。
   资格阶段没有对 Product Runtime 的发布授权。
4. 每项须先证明完整调用观察、跨根/owner/workspace/task/action 隔离、SDK schema 拒绝与原生停止；
   再实现最小领域准入接入。接入必须证明写前持久认领、最多一次不同输入修正、未知不返还额度、
   同键异输入拒绝、原结果与领域事务一致、取消/并发/重启行为和普通用户操作不误扣额度。
   每项证据独立判定；不根据公共函数或其他工具的通过自动标记完成。
5. 通过上述门槛的具名动作可以作为已授权 H4 开发接入现有私有凭证和纠错合同，不再为同一接缝
   重复请求逐工具架构审批。超出本决策前提、引入新调度器或变更业务授权的方案仍需新的 ADR。
6. Backend 继续持有领域不变量和持久预算，Agent-to-Domain 仍经 BYQ MCP，DSH 继续控制执行与通用停止。
   不 fork DSH、不建立第二 Agent harness、不让 DSH 访问业务数据库；私有摘要不进入浏览器或公开 trace。
7. 本决策仅补充开发/隔离资格范围。已有 Draft PR/CI 授权按原记录执行；不新增主线合并、生产部署、
   真实模型调用、历史研究续跑、数据扩容或 release/tag 授权。Product Phase 97 不变。

## 首个候选的可审查实施范围

`byq_strategy_version_create`：复用原 task、draft artifact 和 idempotency key，增加可信 AgentRun 的可核对引用；
先运行官方进程观察/根隔离/停止探针，再将版本生成及回执确认放入现有准入事务。
不重新执行或替代策略审批，不改变生成版本的合法来源要求。身份错误、存储错误、来源证据损坏不能伪装成可修正参数错误。
资格失败则不启用该动作；原记录和预算保留。
