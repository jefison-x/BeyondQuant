# ADR-0120：会话与回测共用宽基指数历史补数

- Status: Accepted
- Accepted: 2026-11-25，维护者明确回复“接受 ADR-0120，继续开发”。
- Date: 2026-11-25
- Scope: 沪深 300（000300.SH）和中证 500（000905.SH）的指数日线、相关上交所日历、原会话自动续研及回测基准复用。
- Related decisions: 本提案补充 ADR-0118 的会话补数范围与 ADR-0119 的续研读取范围，沿用 ADR-0030 的回测基准冻结规则。

## 背景

生产会话请求两只宽基指数的十年行情，个股日线入口返回 0 条，该会话未创建补数回执。此前的生产盘点在独立指数库中找到沪深 300 的 35 条记录，中证 500 的记录为 0。现有 Data Worker 已能为回测拉取 Tushare 指数日线，原会话的自动补数和续研目前只覆盖约定的个股研究范围。 [P0 开发计划](../../roadmap/TUSHARE_DATA_CENTER_EXPANSION_PLAN.md)

## 提议

1. Backend 增加明确的指数历史范围。普通用户可在自己的活动个人研究会话自动申请这两只指数中的一只或两只，范围最长为十个公历年，包含所需交易日历。每个个人工作区沿用现有的会话补数并发上限。权限依据会话、原执行及所需数据范围核对，按 ADR-0118 继续处理个股请求。
2. 助手经 BYQ MCP 申请和读取。现有 Data Worker 通过 Tushare API 复用日历、指数适配器和持久任务，按规范数据类型、指数和缺失日期组织分段。已核验区间可直接复用，重叠请求复用同一份同步结果。指数日线及日历的任务凭据和回执分别保持已有供应商、会话和任务边界。
3. Backend 对照交易日历核对两个区间的首尾、所有适用开市日、标的、单位及内容摘要。缺少日历、尚未发布、范围超限和供应商失败分别保留状态。完成通知绑定经核验的确切数据版本和原用户消息。
4. 后台续研仅获该回执对应指数、日期及版本的只读权限。读取可分页，分页必须核对同一数据版本。原会话消费者复用现有结算、取消、幂等、未知结果和只读权限保护。范围或数据版本变化时，读取返回明确状态。
5. 已授权回测沿用现有基准声明，经同一数据中心能力补齐或复用已核验的指数范围，再将基准序列及摘要冻结在输入中。共享同步记录和各消费者回执分别留痕，取消单个会话只影响其自己的续研与需求绑定。

## 验收与回退

- 测试环境以 2016-11-25 至 2026-11-24 为对照。普通用户提交一次原问题后关闭页面。后台完成日历与两只指数的实际覆盖检查，原会话复读该版本并继续回答。
- 已具备策略及其他数据的回测选用重叠区间，证明能复用同一份已入库指数数据。检查重复和并发请求的实际同步记录、权限隔离、范围或版本失配、失败后对账，以及重启后的回执与接续。
- 回退按该类型关闭会话授权和对应续研能力。已核验指数数据、会话回执和已冻结的回测记录一并保留。
