# 任务续接预算账本合同（ADR-0065）

状态：已接受决策下的 contract-first 设计；**尚未实现持久账本、Product 授权入口或消费者**。
当前没有合格的全调用预算执行器，不能凭此文档或计数器开启后台模型。

## 所有权和许可

Backend 持有预算及任务授权事实；Gateway 只消费已准入意图并使用既有 Runtime seam。
DSH 保持模型/子 Agent/搜索/压缩编排所有者，不能访问业务数据库。没有模型可调用的增额工具。

每份许可必须绑定精确 owner、workspace、conversation、task、不可变 grant version、
用户确认的 artifact lineage 和确认记录。Backend 从已鉴权 Product 身份及任务目录解析关联，
不信任请求自行声明的 owner 或“最新任务”。历史无绑定任务不自动补绑/授权。
明确 token/费用额度不得从开发者测试授权、策略审批或模型解释推定；没有默认金额。

24 小时有效期、最多 8 个后台回合、每回合 900 秒是独立上限；较小的用户额度优先。
绝对 expires_at 在持久确认时确定，不能按重试或服务启动时间重算。
金额必须使用整数最小计量单位，固定币种、Provider、model 及保守价格上界的版本和有效期；
不得使用浮点金额或把估算 token 宣传为精确账单。价格/执行覆盖缺失或过期时禁止准入。

## 原子准入与幂等

在同一 Backend 事务中锁定许可，复核 active 身份/成员关系、会话归属、任务非终态、
许可未撤销/过期、制品范围及剩余额度，先持久预留，再发布可消费意图。
身份禁用、任务取消和撤销必须与准入采用一致的锁顺序；事务提交是准入线性化点。
已准入回合与尚未准入意图分开呈现，不声称 Backend 和 Runtime 可以跨服务瞬时原子取消。

去重键绑定 task、grant version、可信领域事件身份及固定执行输入摘要；同键异输入拒绝。
重复通知、并发消费者、租约失效或进程重启均不得另扣一个回合或重新授予额度。
同一预算不允许并行的未结算回合；保留既有一次意图的准入身份用于精确查询。
预算 reservation 不是动作 approval：训练、预测、回测等仍逐动作检查授权。

## 提交与结算

状态区分 reserved、accepted、settled、outcome_unknown；保留单调的持久身份和原始额度。
HTTP 成功、模型 completed、业务动作完成和研究目标完成不是同一回执。
丢失接收回执先按原幂等身份核对；普通 404、超时、空列表或租约到期不能证明未执行。
无法证明结果时保留预留并阻止该预算再准入，不自动退款、重置或扩额。

只有可信执行器能够证明覆盖全部调用、绑定原 reservation 且结算唯一时，才能返还未用额度。
重复相同结算返回原回执；冲突结算隔离审计。未知结算不能用零用量补齐。
退款后的额度不复活已撤销、取消、到期或禁用的许可。

## 执行器资格门槛

必须在请求发出前预留可证明的输入与输出上界，覆盖根请求、子 Agent、搜索、压缩、
Provider 内部重试和并发；缺少任何一项就禁止后台启动。
资格证据固定到 SDK/runtime、composition 和执行器实现的准确身份；升级或配置变化必须重新验证。
不能接受普通请求中的 `qualified=true`，也不能凭包名、用量事件或注册表 AVAILABLE 状态放行。

当前 SDK 的 max_tokens 只是每请求输出参数。当前 composition 有 token-meter，
但没有加载 agent-budget；这不证明所有公开扩展都不可能实现，只证明当前组合尚不合格。
ADR-0038 不允许把未经验证的外置包直接装入 Product；ADR-0065 不授权 Provider 代理或未公开 hook。

## 必需验证矩阵

- 精确额度与超额一单位、缺失/过期价格、缺失覆盖、布尔/负数/非整数额度均有拒绝测试。
- 真实 PostgreSQL 并发预留不超额；重复事件、重启、回执丢失不重扣/重执行。
- 撤销/禁用/取消与准入竞争，证明事务顺序；不靠单进程锁模拟跨服务保证。
- 根、子 Agent、搜索、压缩、重试分别通过隔离脚本 Provider 的发出前拒绝测试。
- 未知用量保留预留；迟到、重复、冲突结算；重新授权不能抹去旧未知支出。
- Product 用户可读剩余额度、阻塞原因和撤销状态；浏览器只经 Product API，需真实浏览器验证。
- 付费测试仅用于无密钥资格通过后的关键点；测试成功不替代用户的任务执行许可。

以上均为待实现/待验收要求，不是已经通过的测试清单。
