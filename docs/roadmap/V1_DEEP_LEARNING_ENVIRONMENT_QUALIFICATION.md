# 深度学习环境资格调查（0.10 前置）

Status: Draft / not_measured — 依据 [ADR-0074](../architecture/adr/ADR-0074-data-baseline-and-qualification-boundaries.md)。
用于决定 0.13（MLP/LSTM/GRU/TCN）与 0.14（小型 Transformer）的运行环境；未实测前不宣称支持。

## 需求

1.0 要求独立深度学习 Worker 在**有界资源**下稳定运行：序列输入、长训练、取消、重启、
模型加载；公布每个 profile 的实测规模、内存、线程、并发、墙钟与制品上限。GPU 为可选，
仅在通过验收的设备/驱动/模型组合上宣称。

## 当前事实

- 本机宿主 Python `3.14`，未安装 `torch`（`import torch` 失败）；当前生产/CI 未包含深度学习依赖。
- 现有 ML 栈为传统 CPU profile（Phase 84–86），不含深度运行环境。
- 模型持久化沿用现行禁令：禁止 pickle/joblib 与任意对象加载；候选格式须逐 profile 资格验证。

## 待测矩阵（每 profile 一行，`not_measured` 直到实测）

| 项 | 候选 | 证据要求 |
|---|---|---|
| Python / 框架 | 待定（须与现有锁版本兼容） | 精确版本锁与镜像 digest |
| 模型格式 | 安全可校验格式（非 pickle） | 完整性校验与重载一致性 |
| CPU profile | 默认必须可用 | 实测规模、内存、线程、墙钟 |
| GPU profile（可选） | 待资格 | 设备/驱动/精度、镜像大小、峰值显存 |
| 镜像大小 | — | 实际构建产物 |
| 代表性训练/推理 | 有界规模 | 耗时与峰值内存（CPU；GPU 如启用） |
| 取消/重启/加载 | — | 故障矩阵：取消、Worker 被杀、服务重启、迟到结果 |
| 数值一致性 | — | 确定性路径严格比对；其他路径预冻结容差与理由 |

## 判定规则

- 未知项保持 `not_measured`；不根据“包可安装”推定支持。
- 目标规模若必须 GPU，则先修订支持环境与安装说明，禁止用微型测试冒称规模化支持。
- 依赖与镜像资格须有具名 Accepted ADR（GPU、新 Worker 拓扑）；本调查不采购 GPU、
  不发布镜像、不改运行能力。

## 下一步（0.10）

3. 产出是否满足 0.13 门槛的结论；不满足则登记 `blocked` 并修订计划。
