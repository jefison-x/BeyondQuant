# 许可与风险说明（非规范摘要）

以根 [LICENSE](../../LICENSE) 为准。本说明不新增授权，也不是律师意见。

- **能免费学习吗？** 仅为本人行事的自然人可以进行非商业学习、研究、实验和模拟测试。
- **能用自己的资金实盘吗？** 不能。人工下单、外接券商、复制信号或改代码都不构成实盘豁免。
- **学校/公益研究机构能免费用吗？** 不能依本公共许可进行机构使用，须另行书面授权。
- **在校学生或公司员工能用吗？** 为本人业余研究且不代表机构行事可按许可使用；机构课程、
  职务研发、受托任务不因个人账户或“科研”标签而获得许可。
- **能 fork 或分享吗？** 合格个人可按 LICENSE 分享；保留许可/版权/第三方声明、标明修改。
  GitHub 站内浏览/fork 权利按其服务条款处理，不等于取得机构运行、商业或实盘许可。
- **维护者以后能商业化吗？** 对其自有或已获足够授权的部分可以，不能覆盖第三方权利。
- **提交 PR 后版权归谁？** 原创贡献版权仍属贡献者；CLA 另授维护者商业与再许可权。
- **软件会自动取得我的策略和数据吗？** 不会。独立用户产物不因使用 BYQ 就转让或改用本许可。
- **禁止实盘就绝对免责吗？** 不能如此承诺。用途限制、显著风险告知和免责条款各有作用，
  均受强制性法律限制，不能替代安全设计、如实说明和专业法律审查。

例如，在中国法适用时，《民法典》第 496 条涉及格式条款的提示和说明，第 506 条限制
人身损害以及故意/重大过失造成财产损失等免责。单纯弹窗或勾选也不能自动证明履行了
提示说明义务。参见[民法典](https://www.court.gov.cn/zixun/xiangqing/233181.html)与
[合同编通则司法解释](https://gongbao.court.gov.cn/Details/f4722cf61c92a585f04b2ecd334f5b.html)。

安装者应阅读根许可、README 风险提示和本说明；不得用“绝对安全”“稳赚”或“无论什么
情况均不负责”等措辞宣传。任何另行实盘/商业交付前需重新审查功能安全、合规和合同。
