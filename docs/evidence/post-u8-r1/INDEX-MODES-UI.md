## 功能清单

- 创建页明确选择“持续跟踪指数”或“固定历史快照”，默认前者。
- 历史模式必须明确日期；缺失时仅提示，不发创建请求。
- Product API 提交明确 tracking_mode 和 YYYYMMDD 日期，提交后表单重置回默认模式。
- 详情从当前池的持久 producer definition 显示更新方式和冻结日期。
- 历史池不提供刷新成分；未知/错误池定义不提供刷新，不猜测为持续跟踪。
- 持续跟踪池仍提供刷新；已有研究的冻结快照不会跟着当前池版本改写。
