# H4 模拟账户六类命令原回执

2026-09-13，候选 `.75`，沿用 ADR-0021 与现有 Product 身份边界。

创建、下单、结算、风险控制、换绑、删除按原键读取 owner/workspace 内持久回执。
创建账户与初始资金流水、创建审计同事务，并以原键及名称锁序列化；页面在请求发出前
持久保存冻结参数，刷新可只读核对或显式原键重试。新写仍须满足原版本、权限及领域校验。
旧结算已存在且同输入的新键写入回执别名，不重复结算快照或流水。删除后的原审计仍可核对。
MCP 只扩展既有读取工具的闭合查询；没有新增账户写入权限。请求失败或不完整回执不算成功。

验证：
- Backend 模拟命令、并发恢复、交易及 API 定向21项通过；结算别名追加后相关17项通过（重叠，不相加）。
- 六类回执测试3项通过，覆盖删除后原事实、错 owner/workspace/account/operation 拒绝及结算别名只有一份快照和流水。
- 前端保存与原 API 测试13项通过，类型检查及构建通过；MCP 构建和纸面工具负例通过。
- 真实 Gateway/Product API 浏览器1项通过（3.6秒）：账户提交成功后丢回执→刷新只读恢复，随后订单提交成功再丢回执→刷新只读恢复。
  实际创建请求1次、订单请求1次，原订单ID不变，1500初始现金扣除1000成交额及5手续费后为495。
- 初次浏览器失败原因是长股票池名称挤压原七列表单，输入框不可操作；改为三列自适应布局后通过。失败历史不抹去。
