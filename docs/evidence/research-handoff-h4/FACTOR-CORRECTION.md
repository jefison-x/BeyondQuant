# H4 因子调用有界纠错

2026-09-13；Accepted ADR-0066 的逐工具扩展审计，Product Phase 97 不变。构建 `.66`。

## 边界与改动

`byq_factor_compute` 现在要求精确 AgentRun、任务和原键；官方调用观察提供根身份凭证。
MCP 用可信 trace 替换模型 trace，并仅在明确执行前 425 时有限等待凭证；超时、409、5xx
不自动重放写入。Backend 复用现有根/任务/动作纠错桶和认领事务；因子 Artifact 与成功回执
同事务提交。原失败输入换键不能再次执行，一次修正后预算不重置；用户直接操作不扣 Agent 预算。

仅 `FactorValidationError` 可分类为可修正错误，存储或身份异常不冒充参数错误。
字段和错误类别使用闭集，未知字段名、输入值和异常原文不公开；因子名称允许值来自合同常量。
MCP 保留官方 schema 拒绝，耗尽反馈通过既有官方根进程停止接缝生效。

因子输入包含有界表格，单独允许 4 MiB / 131072 canonical 节点；策略仍为 256 KiB / 8192。
这是证据上限，不能代替 Backend 的证券、日期、来源、生命周期、覆盖及结果数量校验。
没有第二循环调度器、DSH fork、新数据库表或历史许可回填。

## 验证

- 改动后：相同真实官方进程，观察、根隔离、原生停止 3 项通过；模型/MCP 为隔离回环测试端点，
  没有真实模型、Provider 或生产执行，因此不能替代 H5 模型研究闭环。
- 当前 Backend 源码和共享合同完整挂载到标准 `/app` 布局：因子 HTTP/恢复及纠错事务 29 项通过，
  包括真实 PostgreSQL 并发撤销等待提交；无凭证不执行、重复失败阻断、合法修正、重开 Store 后复用。
- MCP 编译、因子错误/未知回执翻译、官方 SDK schema 拒绝、真实 BYQ MCP 服务工厂测试通过。
  服务工厂确证因子可信根标识、trace 替换和停止反馈；其 Backend 为隔离测试端点。
- 私有证据合同 8 项通过，含最大形状表格、换 key/child 不算进展和原策略限额保留。
