# Agent 会话运行参数

本补充维护切片落实 Accepted ADR-0111 中的可选执行参数 UI。此前设置页只展示自动接续开关，遗漏了合同已有的 15 个数值参数；现已在本人会话设置中统一编辑，并要求显式保存。

参数按调用与并发、输入/输出/工具载荷、自动接续与时长分组。自动接续仍为独立开关。所有数值字段均显示中文名称、单位和适用范围；正整数生效，空白保存为 `null`（不限），不配置隐式默认上限。每次用户请求或自动接续按一轮计算；子 Agent 时长逐个计算。输入限制以字节表示；输出累计 token 是每轮各请求声明上限之和，不代表实际使用量。

页面仅对现有 owner/workspace/conversation 读取到的会话显示当前服务端参数。字段编辑只改本地草稿；无效值（零、负数、小数、非数字或超出 JavaScript 安全整数范围）显示字段错误且不允许保存。保存提交完整合同对象和当前 `expected_revision`；成功后用返回记录更新页面。若 PUT 结果未知，只执行一次 GET 核对，不自动重放。切换会话或身份时继续使用现有 generation 与 owner/workspace fence；A→B→A 时待完成保存会在同一会话下重新读取准确值。

静态验证：`npm --prefix apps/frontend run build` native exit 0（包含 `vue-tsc --noEmit` 与 Vite build）；`git diff --check -- apps/frontend/src` native exit 0。stdout、stderr、退出码原件和最终源文件 SHA 清单保存在 `.ci-artifacts/agent-runtime-parameters-v1/`。本切片未写或运行功能测试，未自行操作浏览器、模型、数据库、容器或服务。Root 按最新范围只读查看保留页面中的当前参数；保存、输入校验和执行效果的真实验证留待后续。
