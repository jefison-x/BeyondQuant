## 交付

- Backend 从原任务、审批、四类业务作业、原会话活动和续接账本生成只读一致快照。
- 原目标及检查点继续使用现有持久化记录，避免另存会过期的执行状态副本；接口不会更改 lifecycle。
- MCP 原任务详情附带交接；浏览器通过 Gateway/Product API 查看、刷新交接面板。
- 研究目录将 running 表达为“未完成”；任务记录和实际执行事实分开。
- 终态优先；缺证据、未知回执和截断记录要求核对；许可不等于排队，审批 submitted 不等于作业存在。
