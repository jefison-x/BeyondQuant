# H5 历史指数单次快照准备

2026-09-13，`.68`。遵循 Accepted ADR-0062/0045，不推进 Product Phase。

## 已实现

既有 data-demand 增加封闭 `index_snapshot` 范围：六个 canonical 指数、明确非未来日期、62天
窗口，最多3个月的既有 index_weight dataset。无需先有股票池，需求与修复引用同事务持久化。
既有 Data Worker 处理此类需求时不下载交易日历或股票日线；完整闭月缓存复用原有校验路径。
单次时点 readiness 按上海日期核对抓取时间、来源、行数、权重和快照哈希，不能选择未来成分。
缺失和证据损坏均不能成为ready。新列不增加，只将既有 stock_pool_snapshot_id 允许为空。

历史池创建和物化都限制在相同62天窗口内，缓存丢失时等待数据，不退到窗口外的旧快照。
持续跟踪池逻辑不改变。快照准备完成只意味着可以创建这一时点的固定池，明确不代表历史
调仓序列、日线/复权/生命周期数据或回测已就绪。

Product 股票池页面可提交准备并查询进度，管理员门禁不变；数据中心区分指数时点和股票范围。
浏览器按指数/日期构造稳定原键，因此刷新及丢回执后仍可精确读取原需求，不另建重复请求。
所有浏览器请求经过 Gateway/Product API；没有浏览器→Backend/MCP/Provider通路。
