# 模型研究与回测

- 模型研究位于 `/model-research`：定义研究 → 可信训练 → 样本外预测 → 冻结信号 → 回测。页面主动操作直接确认并执行；小巴发起的审批统一在全局审批中心处理。
- 页面能力来自动态注册表，支持兼容 LightGBM 单次验证、LightGBM/Ridge 净化走步验证，以及用户明确选择的沪深300市场状态专家方案。
- 必须选择冻结股票池并保证预测区间位于训练和模型选择之后。市场状态方案额外使用冻结的沪深300当日及历史数据，不读取未来行情。
- 小巴会先查询当前已资格验证的封闭模型能力，再分页定位研究目录；只有选中研究后才读取详情，不会下载模型对象或历史大结果。
- 用户未明确要求市场状态时，小巴默认提出单模型净化走步研究，不自动扩大为多专家训练。小巴发起的策略审批必须进入全局审批中心，智能体不能自行批准。
- 审批中心批准后，系统回到原会话并继续；小巴可按逐动作授权创建、查询或取消训练。训练完成后，可创建并查询样本外预测。可信 Worker 会同时冻结标准信号并返回派生回测任务，小巴不读取模型对象或自行计算预测/信号。
- 用户明确要求后，小巴可对预测返回的派生回测任务执行或取消；不得用通用策略信号任务替换 ML lineage，也不得在状态完成前声称预测、信号或回测已完成。
- 回测管理位于 `/backtest`。可创建、运行、取消、比较，并查看绩效、成交、持仓、风险、基准和 lineage。
- 新策略在用户未指定基准时默认声明沪深300（`000300.SH`）；回测向导展示已批准策略版本实际冻结的基准。历史版本未声明基准时不会伪造对比结果，需要先创建并批准含基准声明的新版本。
- 回测必须消费已批准策略和匹配冻结信号。小巴先用 `byq_backtest_task_prepare` 做零写入预检；用户明确要求后再逐动作创建、执行或取消任务。
- 任务输入只包含研究任务、策略版本、冻结股票池、日期、参数和执行偏好；不得让用户或模型构造 raw bars/signals，也不得跳过审批。
- 回测只消费冻结信号，不加载模型、不重新训练、不重新判定市场状态，也不重新排名预测。
