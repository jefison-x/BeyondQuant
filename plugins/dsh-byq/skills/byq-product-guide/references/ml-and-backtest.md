# 模型研究与回测

- 模型研究位于 `/model-research`：定义研究 → 人工批准 → LightGBM 训练 → 样本外预测 → 冻结信号 → 回测。
- 必须选择冻结股票池，并给出严格前后分离的训练、验证和预测窗口；当前只开放已验证的 LightGBM 回归能力。
- Phase 77 小巴可以准确解释和导航模型研究，但尚不能通过对话创建或训练；不得声称已经执行。
- 回测管理位于 `/backtest`。可创建、运行、取消、比较，并查看绩效、成交、持仓、风险、基准和 lineage。
- 回测必须消费已批准策略和匹配冻结信号。小巴先用 `byq_backtest_task_prepare` 做零写入预检；用户明确要求后再逐动作创建、执行或取消任务。
- 任务输入只包含研究任务、策略版本、冻结股票池、日期、参数和执行偏好；不得让用户或模型构造 raw bars/signals，也不得跳过审批。
- 回测只消费冻结信号，不加载 LightGBM、不重新训练，也不重新排名预测。
