# 股票池与规则策略

- 股票池管理位于 `/stock-pool`。custom 是固定自定义成分；index 按可信历史指数权重物化；dynamic 使用封闭时间点规则物化。
- 回测、策略和模拟操盘引用不可变股票池快照；以后编辑股票池不会改写历史运行。
- 策略管理位于 `/strategy`，顺序是草稿 → 校验 → 不可变版本 → 人工审批 → 冻结信号 → 回测。
- 小巴可创建有界 custom 股票池，以及封闭目录中成分已验证的 index 跟踪股票池。先按请求日期核查目录，提交后查询生成状态并取得不可变快照；不能把排队说成已生成。动态生产和生命周期删除仍仅提供页面引导。
- 策略代码是可审计领域制品，不是应用源码；Product Agent 不修改 BeyondQuant 源码。
- 用户要求某个历史时点的一次性成分池时，明确日期并使用 `tracking_mode=historical_snapshot`；持续跟踪指数才使用 `follow_index`。历史模式不会随当前成分更新，不能把单次历史快照说成多年逐期成分序列。缺少目标日期数据时保留缺口，不以当前成分替代。
